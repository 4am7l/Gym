A web application designed for gym administration, managing members, tracking subscriptions, and streamlining daily operations.

## Purpose

The main objective of this system is to simplify gym management by eliminating manual tracking. It provides a centralized dashboard for administrators to register new members, monitor active and expired subscriptions, record payment receipts, and manage daily gym operations seamlessly.

## Key Features

- Member Management: Add, edit, and search gym members efficiently.
- Subscription Tracking: Monitor membership plans, renewals, and expiration dates in real time.
- Payment Integration: Support for recording transactions, payment receipts, and payment methods.
- Database Integration: Direct connectivity to Supabase for secure cloud data storage and retrieval.
- Responsive Interface: User interface optimized for both desktop and mobile screens.

## Tech Stack & Roles

- HTML5: Structuring the web application content and user interface layouts.
- CSS3: Styling, custom UI components, animations, and responsive layouts.
- JavaScript: Client-side logic, dynamic UI updates, and handling application interactions.
- JSON: Data exchange and structured configuration management.
- Supabase: Backend-as-a-Service providing database storage and API authentication.
- Render: Cloud platform hosting and deployment for live site access.
